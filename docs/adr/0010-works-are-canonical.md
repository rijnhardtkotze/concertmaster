# Works are canonical records from the start

Programmes link to canonical Work records (Composer, title, catalogue number) rather than holding free text. This makes it possible to ask "where is this Work being played?" across the country. Matching uses Composer, normalised title and catalogue number where one is given. When no match is found, the Work is created automatically and listed in the Review issue for information; it doesn't hold up the listing.

## Considered Options

- **Composer as a record and the work title as text**, adding Works later. Rejected: backfilling Works later means re-matching every programme ever stored.
- **Blocking a listing until a new Work is reviewed.** Rejected: it costs too much of the weekly review time.

## Consequences

- Duplicate Works will creep in, such as "Eroica" vs "Symphony No. 3". This needs a merge-Works action and alternative names for Works.
